# NDN Ish Website

Static brand website for NDN Ish.

## Project Structure

- `index.html` - homepage markup and content
- `styles.css` - visual design and responsive layout
- `script.js` - mobile navigation, product filters, and signup toast
- `assets/` - logo, collection artwork, and product mockup images
- `netlify.toml` - Netlify static site settings

## Netlify Settings

- Build command: leave blank
- Publish directory: `.`
- Production branch: `main`

## Update Workflow

1. Edit the site files locally.
2. Preview the site by opening `index.html` in a browser.
3. Commit the changes to Git.
4. Push to GitHub.
5. Netlify automatically deploys the latest `main` branch.
